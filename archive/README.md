# Archive

This directory holds superseded experiments and generated artifacts that used to live in the
repository root. They are kept for history, not used by the current Go CLI under `cmd/`:

- `cli-tool/` — early standalone CLI experiment (ignored by git).
- `scanner/` — empty scaffold directories from that experiment.
- `code-map/` — hand-written map artifacts superseded by `.carto/graph.json`.
- `chunks/` — generated source chunks from an earlier indexing approach.

Do not import from these directories. If you need historical detail, see the git history for
their original paths.
